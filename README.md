# 🛒 Carrinho de Compras

Projeto desenvolvido para praticar lógica de programação com **JavaScript**, manipulando elementos do DOM e simulando o funcionamento de um carrinho de compras.

## 📖 Sobre o projeto

A aplicação permite adicionar produtos ao carrinho, atualizar quantidades automaticamente e calcular o valor total da compra em tempo real.

Este projeto foi desenvolvido com foco em praticar conceitos fundamentais de JavaScript, como:

* Manipulação do DOM;
* Eventos;
* Funções;
* Variáveis e constantes;
* Operações matemáticas;
* Template Strings;
* Atualização dinâmica da interface.

## ✨ Funcionalidades

* Adicionar produtos ao carrinho;
* Selecionar a quantidade de itens;
* Cálculo automático do valor total;
* Limpar o carrinho;
* Interface simples e intuitiva.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (ES6)

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/DacolDaniel/carrinho-compras.git
```

2. Entre na pasta do projeto:

```bash
cd carrinho-compras
```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências.

## 🎯 Objetivos de aprendizagem

Durante o desenvolvimento deste projeto foram praticados:

* Manipulação de elementos HTML com JavaScript;
* Captura de eventos do usuário;
* Atualização dinâmica da interface;
* Organização de funções;
* Cálculo de valores e controle de estado do carrinho.


## 📚 Aprendizados

Este projeto foi importante para consolidar conhecimentos sobre JavaScript puro (Vanilla JS), especialmente na manipulação do DOM e na criação de aplicações interativas sem o uso de frameworks.
